## Regelkoll

- [x] Inga djurnamn: "katten", "nallen", "farmor", "farfar", "bussen"

- [x] Samma mönster tre gånger: *"Bussen stannar. Titta! Vad ser katten?"* → namnet → *"Bussen åker igen. Brum, brum!"*
- [x] Kritan ritar två gånger: bussen (introt) och hjärtat
- [x] Inget läskigt: katten är glad hela vägen och nallen är med. Inga ord som rädd, farligt eller modig
- [x] Fniss: 23 (högst 3–4)
- [x] Ingen ny musik
- [ ] **Avsteg:** 3 platser (hållplatsen, bussen, farmors dörr)
- [ ] **Avsteg:** 3 figurer plus två små gäster i fönstret (kaninen i pulkan, fågeln). Båda finns redan och syns bara små och långt bort
