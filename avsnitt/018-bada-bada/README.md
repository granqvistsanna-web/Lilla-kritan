## Berättelsen mot sången
| Del i sången | Bild |
|---|---|
| Intro | kritan ritar badkaret, zoom in i teckningen |
| Vers 1 | kaninen kommer in lerig, skummet växer, hopp i badet |
| Refräng | refrängdansen i badet: plaska, peka, gnugga, blåsa, plask ×3 |
| Vers 2 | öronen, magen, skum på nosen som blåses bort |
| Refräng | samma som förut |
| Vers 3 | "Var är fötterna?", paus 4–5 s, sedan sticker fötterna upp: tittut, räkna tårna |
| Mellanspel | kaninen kliver upp och fryser, når inte handduken på kroken |
| Vers 4 | lammet kommer med handduken: "Varsågod!" – "Tack!" |
| Sista refrängen | torka, kram |
| Svans | en sista bubbla spricker, kritirisen runt båda |

## Regelkoll (`format/regler.md`)
- [x] 2 figurer, 1 plats, 2 nya saker, 1 ny pose per figur
- [x] Introt har titel och nummer. Slutet är kritirisen, samma som 005–007 och 014–017
- [x] Inget platsbyte, så inget kritsvep. Zoom in i teckningen i början
- [x] En fråga till tittaren med paus 4–5 s: *"Var är fötterna?"*, sedan visar kaninen svaret
- [x] Vardagshandling: bada och torka sig. Tack: lammet ger handduken, *"Varsågod!"* – *"Tack!"*
- [x] Upprepning: "Var är …? Skrubba!" tre gånger, refrängen tre gånger
- [x] Ett litet problem, löst tillsammans: handduken hänger för högt, lammet hjälper
- [x] Inget läskigt: inget vatten i ögonen, ingen gråt, kaninen fryser bara lite
- [x] Inga djurnamn i det som sjungs: "kaninen", "lammet"
- [x] Egen sång, inte en ny text till en känd melodi
- [x] Sången går att klippa ut som Short: refräng + vers 2 + refräng (≈ 45 s, tider när tagningen finns)

## Öppet
1. **Suno-tagning.** Lyssna efter pausen efter "Var är fötterna?". Blir den kortare än 4 s får bilden hålla fötterna gömda en stund in i nästa rad.
2. **Längden** blir ca 2:50–3:10 med introt, inom 3–4 min om tagningen blir 2:40 eller mer.
