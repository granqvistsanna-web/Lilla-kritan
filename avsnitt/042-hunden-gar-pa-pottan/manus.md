## Så rör det sig

| Rörelse | Hur |
|---|---|
| Trippar in, travar | riggens gång (`L.ROR.ga`), stannar före repliken |
| Puffar bollen | som 021: hukar, puffar, bollen i en liten båge. Ingen snurr |
| Flämtar | tungan ute, `flamt-valp`, kroppen andas |
| Håller glaset | glaset vid tasstoppen som 020:s tvål, tassen framför glaset, huvudet lutar mot det. Armen är rak, ingen böj |
| Dricker | glaset lyfts lugnt till munnen, vattennivån sjunker i tre steg (`klunk` per steg) |
| Kritan ritar vatten | kritan svävar ovanför glaset, vattnet fylls i nerifrån och upp på ca 1,5 s, litet glitter |
| Magen blir rundare | magfläcken skalas 1,0 → 1,06 → 1,12 → 1,18, ett steg per tomt glas |
| Behöver kissa | lugnt vick från fot till fot (sidled ±6 px), svansen stilla och rak, öronen upp. Inga korsade ben |
| Sitter på pottan | pottan glider in framför hundens nedre del som i godnattsagorna, hunden sjunker lite |
| Lättad | ögonen halvslutna en stund, öronen sjunker mjukt, sedan öppna glada ögon |
| Sträcker sig | `strack` upp, armen rakt upp mot fönsterblecket, når inte. Tredje gången ett litet skutt |
| Klättrar på fåtöljen | två lugna skutt: upp på sitsen, upp på armstödet. Ingen klätteranimation |
| Kramar nallen | nallen framför kroppen, tassen framför nallen, huvudet lutar mot den, blundar kort |
| Glatt skutt | 20 px upp, tryck ihop före och efter. Inget studs |
